# Pancake Frontend V2

Frontend React/Vite độc lập cho hệ thống Pancake. Phase 0 + 1 tập trung vào hạ tầng ứng dụng và xác thực.

## Chạy local

```bash
npm install
npm run dev
```

Ứng dụng chạy tại `http://localhost:5173` và đọc API base URL từ `VITE_API_URL`.

## Kiểm tra build

```bash
npm run lint
npm run build
```

Không đưa token, mật khẩu hoặc production API URL vào source hay file môi trường được commit.
